# Product

## Register

brand

## Users

Developers, collaborators, and curious visitors arriving through Luis Diaz's GitHub profile.
They should immediately encounter a memorable piece of creative code rather than a conventional portfolio template.

## Product Purpose

The site is a single interactive mathematical artwork that introduces Luis through the work itself.
Success means the visitor pauses, experiments with the simulation, and leaves with a clear sense that Luis enjoys code, mathematics, and unusual digital experiences.

## Brand Personality

Curious, mechanical, and playful.
The voice is direct and understated so the mathematical motion remains the focus.

## Anti-references

Avoid rounded card grids, translucent glass panels, soft SaaS gradients, dashboard layouts, stock illustrations, and conventional developer-portfolio sections.
Avoid visual effects that decorate the page without emerging from the simulation.

## Design Principles

- Make the code the introduction.
- Let mathematics create the visual identity.
- Keep the interface quieter than the simulation.
- Reward experimentation without requiring instructions.
- Prefer a single strong idea over a collection of portfolio sections.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast for interface text and links.
Provide keyboard controls, clear focus states, a text description of the canvas, and a static composition when reduced motion is requested.
